Flask + Jinja SSR + Ajax(폴링) + MongoDB + Bootstrap(CDN) + JWT. 배포는 AWS EC2(추후).

## 핵심 설계 결정 (v4 MVP)

- **카드 = 채팅 입구**: 홈 피드 카드를 누르면 판매자와의 1:1 채팅 화면으로 이동.
  화면 상단은 물건 정보(사진·가격·상태·판매자), 하단이 채팅. 방은 (글, 구매자)
  조합당 1개 — 재클릭 시 기존 방 재사용. 별도의 상세 페이지 없음.
- **거래 상태 2단계**: 판매중 → 판매완료(판매자 단독 버튼). 예약중 없음.
- **거래 유형 3종**: 판매 / 나눔 / 교환("아무거나" 또는 원하는 물건 직접 입력).
- **결제**: PG 없음. 글 작성 시 계좌 선택 입력 → 채팅 화면의 계좌 줄에서 복사.
  modal 없음. 계좌는 채팅 화면에서만 노출.
- **내비게이션**: 햄버거 → offcanvas 사이드바 5항목
  (Home · Community · 채팅목록 · 거래내역 · 로그아웃). navbar 우측: 검색(P2) + 채팅 뱃지(P1).
- **본인 글 카드 클릭** → 거래내역(판매 탭)으로 안내. 마이페이지 없음.
- **SSR/Ajax 경계(추천안)**: 페이지 이동은 전부 SSR, Ajax는 찜·댓글·채팅 폴링·판매완료 전환 4곳만.

## 우선순위

- **P0**: 인증(JWT) · 거래 글 작성/삭제(사진 1장) · 홈 피드(반응형 그리드) ·
  카드 → 1:1 채팅(3초 폴링, innerHTML 전체 교체) · 판매완료 · 계좌 복사
- **P1**: 거래내역 구매 탭 · 글 수정 · 안 읽음 뱃지 · 나눔/교환 필드 분기
- **P2**: 커뮤니티 전체(질문·정보공유 게시판) · 검색 · 유형 필터 · 찜
