# 크래프톤 당근 (Krafton Carrot)

> 크래프톤 정글 구성원 대상 중고거래·나눔·물물교환 웹 앱. 2박 3일 팀 프로젝트.
> (설계 스냅샷 2026-08-24 — 이후 팀 논의로 바뀔 수 있음)

## 와이어프레임

| 파일 | 내용 |
|---|---|
| `wireframe/wireframe-v3-final.html` | **최종본.** 브라우저로 열면 클릭형으로 동작. 웹 UI(햄버거+offcanvas), P0/P1/P2 우선순위 표시, 판매자 단독 완료 |

## 확정된 스택

Flask + Jinja SSR + Ajax(폴링) + MongoDB + Bootstrap(CDN) + JWT. 배포는 AWS(추후).

## 핵심 설계 결정

- **아고라**: 거래 글마다 공개 협상 스레드(로그인 유저 전체 공개, 자유 채팅). 판매자가
  메시지 옆 "🤝 이 사람과 거래" 버튼으로 상대 확정 → 예약중 + 1:1 채팅 개설.
- **거래 상태**: 판매중 → 예약중(판매자 확정) → 판매완료(판매자 단독 버튼).
- **거래 유형 3종**: 판매 / 나눔 / 교환("아무거나" 또는 원하는 물건 직접 입력).
- **결제**: PG 없음. 글 작성 시 계좌 선택 입력 → 구매하기 modal에서 계좌 안내+복사.
  계좌는 modal과 1:1 방에서만 노출.
- **내비게이션**: 하단 탭 없음. 햄버거 → offcanvas 사이드바 5항목
  (Home · Community · 채팅목록 · 거래내역 · 로그아웃). navbar 우측: 검색(P2) + 💬 뱃지(P1).
- **마이페이지 없음**: 거래내역(판매/구매 탭)이 대체. 프로필 수정은 추후.
- **SSR/Ajax 경계(추천안)**: 페이지 이동은 전부 SSR, Ajax는 찜·댓글·채팅 폴링·상태 전환 4곳만.

## 우선순위

- **P0**: 인증(JWT) · 거래 글 작성/삭제(사진 1장) · 홈 피드(반응형 그리드) ·
  아고라(3초 폴링, innerHTML 전체 교체) · 1:1 전환 · 판매완료 · 계좌 modal
- **P1**: 거래내역 구매 탭 · 글 수정 · 안 읽음 뱃지 · 나눔/교환 필드 분기
- **P2**: 커뮤니티 전체(질문·정보공유 게시판) · 검색 · 유형 필터 · 찜

## 잘라낸 것 (기록)

- 제안 카드(금액 조절 오퍼 UI) — 데이터 모델+수락 로직 비용. 나중에 재검토.
- 양측 거래 완료 확인 — 판매자 단독으로 단순화.
- GPS 만남 확인, WebSocket 실시간, 위치 기반 기능 — 범위 밖 (WebSocket은 추후 확장 후보).

## 팀 회의 안건 (미결)

1. **JWT 보관 위치** — 추천: httpOnly 쿠키 (SSR과 유일하게 자연스러운 조합, XSS 방어).
2. **SSR/Ajax 경계** — 위 추천안 승인 여부.
